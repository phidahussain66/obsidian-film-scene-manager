# Scene Manager v1.6

New in v1.6: fold/unfold. Each shot has a chevron to fold it to a thumbnail only; each scene has a chevron
to fold it to its header plus a strip of shot thumbnails. The grid buttons switch all shots (in a scene, or in the
whole project) between thumbnails-only and full cards, and the project header can fold or unfold all scenes.
Fold state is saved.

Install: copy this `scene-manager` folder into `<your vault>/.obsidian/plugins/`, restart Obsidian,
then enable "Scene Manager" under Settings > Community plugins. Open it from the clapperboard ribbon icon
or the command "Open Scene Manager".

Back up first: copy your existing `.obsidian/plugins/scene-manager` folder (it holds data.json) somewhere safe.
There is also a command, "Back up Scene Manager data to the vault".
